# План MVP

Чеклист этапов разработки приложения «Контроль ухода за растениями».

## Этап 0 — Bootstrap monorepo

- [x] Monorepo (`apps/web`, `apps/api`), Docker Compose для MongoDB
- [x] Frontend: Vite + React + TypeScript + Ant Design (`ru_RU`), layout и роутинг
- [x] Backend: Express skeleton, `GET /api/health`, подключение MongoDB
- [x] ESLint через `@llm/linting`, скрипты `dev` / `lint` / `build`
- [x] Базовая документация (`CONSTITUTION`, `AGENTS`, `README`)

## Этап 1 — Модель Plant, GridFS, CRUD API

- [x] Mongoose-модель `Plant` (поля ухода, категория, интервалы)
- [x] GridFS для изображений, генерация превью 128×128
- [x] REST CRUD `/api/plants` (создание, чтение, обновление, удаление)
- [x] Лимит загрузки 5 МБ

## Этап 2 — Распознавание Ollama

- [ ] `POST /api/plants/recognize` — vision через `qwen3-vl:8b`
- [ ] Structured JSON: название, описание, уход, интервалы, категория
- [ ] Обработка ошибок и таймаутов Ollama

## Этап 3 — Добавление растения (frontend)

- [ ] Форма загрузки фото → распознавание → предпросмотр/правка полей
- [ ] Даты полива/подкормки (default — сегодня)
- [ ] Сохранение через API

## Этап 4 — Каталог (frontend)

- [ ] Карточки с превью, названием, двумя прогресс-барами
- [ ] Сортировка: по умолчанию близость полива; альтернатива — подкормка
- [ ] Фильтр по категории
- [ ] Быстрые действия «Полил сегодня» / «Подкормил сегодня»

## Этап 5 — Редактирование и удаление (frontend)

- [ ] Форма редактирования всех полей и замены фото
- [ ] Подтверждение удаления
